GUIDE D’INSTALLATION

Préparer ton ZIP

Où trouver le dossier du jeu ?

Steam sous Windows : dans ta bibliothèque, clic droit sur Celeste → Gérer → Parcourir les fichiers locaux.

GOG Galaxy : ouvre Celeste, puis le menu de gestion de l’installation et choisis l’option qui affiche le dossier du jeu. Depuis GOG hors Galaxy, utilise le dossier choisi lors de l’installation.

itch.io : dans l’application itch, ouvre la page du jeu puis son menu de gestion pour afficher le dossier. Pour une installation téléchargée depuis le site itch.io, décompresse d’abord l’archive obtenue auprès d’itch.

Créer et importer l’archive

  1. Repère le dossier complet de Celeste, avec son exécutable (Celeste.exe ou Celeste.dll) et le dossier Content.
  2. Dans l’explorateur Windows, clic droit sur le dossier → Compresser dans un fichier ZIP ou Envoyer vers → Dossier compressé. Sur macOS, clic droit → Compresser.
  3. Reviens sur cette page, choisis le fichier ZIP dans le cadre d’importation, puis clique sur Jouer. L’archive doit contenir les fichiers du jeu à sa racine, ou dans un unique dossier parent.

Le site vérifie les fichiers indispensables et les installe dans le stockage privé de ce navigateur. L’archive et les fichiers commerciaux restent sur ton appareil : cette application ne les envoie ni à Supabase ni à un serveur de jeu.

Questions fréquentes

Pourquoi dois-je posséder Celeste ?

Le site fournit le moteur WebAssembly, pas le jeu commercial. Utilise une copie que tu as le droit d’utiliser.

Pourquoi le premier démarrage est-il long ?

Le navigateur installe les nombreux fichiers du jeu dans son espace local, puis initialise le moteur WebAssembly. Les visites suivantes réutilisent l’installation.

Où sont enregistrés les fichiers et ma progression ?

L’installation et les sauvegardes locales restent dans le stockage privé du navigateur pour cette adresse web (OPFS). Les sauvegardes cloud sont optionnelles et ne contiennent que les données de sauvegarde exportées par le SDK.

Comment retrouver mes sauvegardes ?

Ouvre les Préférences pour exporter ou restaurer les sauvegardes locales, ou connecte-toi pour utiliser la synchronisation cloud configurée.

Pourquoi dois-je réimporter le ZIP après avoir effacé les données du site ?

Effacer les données du site supprime aussi l’installation et les sauvegardes locales. Il faut alors réimporter le ZIP et, si besoin, restaurer une sauvegarde cloud.
