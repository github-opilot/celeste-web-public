SETUP GUIDE

Prepare your ZIP

Where can I find the game folder?

Steam on Windows: open your library, right-click Celeste, then choose Manage → Browse local files.

GOG Galaxy: open Celeste, then open the installation management menu and choose the option that shows the game folder. If you use GOG without Galaxy, use the folder you selected during installation.

itch.io: in the itch app, open the game page and its management menu to show the folder. If you downloaded the installation from itch.io's website, first extract the archive you got from itch.

Create and import the archive

  1. Find the complete Celeste folder. It must contain the game executable (Celeste.exe or Celeste.dll) and the Content folder.
  2. In Windows File Explorer, right-click the folder and choose Compress to ZIP file or Send to → Compressed folder. On macOS, right-click and choose Compress.
  3. Return to this page, choose the ZIP in the import area, then click Play. The archive must contain the game files at its root or inside a single parent folder.

The site checks for required files and installs them in this browser's private storage. The archive and commercial game files stay on your device: this app does not send them to Supabase or any game server.

Frequently asked questions

Why do I need to own Celeste?

This site provides the WebAssembly engine, not the commercial game. Use a copy you are entitled to use.

Why does the first launch take so long?

Your browser installs the game's many files in local storage, then initializes the WebAssembly engine. Later visits reuse the installation.

Where are the game files and my progress stored?

The installation and local saves stay in this website's private browser storage (OPFS). Optional cloud saves contain only save data exported by the SDK.

How can I access my saves?

Open Settings to export or restore local saves, or sign in to use the configured cloud sync.

Why do I need to import the ZIP again after clearing site data?

Clearing site data also removes the installation and local saves. Import your ZIP again and, if needed, restore a cloud save.
